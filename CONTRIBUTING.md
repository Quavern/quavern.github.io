# Contributing

This repository builds oss.quavern.com. It accepts:

- corrections to the list (`content/projects.json`), the upstream software
  (`content/upstream.json`) or the page copy, in English and French together;
- fixes to the build, the pages' accessibility or their layout.

It does not accept changes to the licence texts through pull requests; write
to hello@quavern.com about the licence instead.

Before opening a pull request, run `node build.mjs` and check `_site/` at a
narrow and a wide width. A contribution is received under the repository's
licence (QOSL-1.0, section 2.5). Issues and pull requests are read; there is
no guaranteed reply delay.
